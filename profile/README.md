## Manage Construction Projects and BIM Workflows With CUBE

CUBE is a [construction project management platform](https://www.cube.ms/) for architecture, engineering, and construction (AEC) teams. It brings project documents, BIM models, revision history, and construction workflows together in one place, following ISO 19650 standards.

### Document Management and BIM Coordination

CUBE provides a shared environment for managing project documents, 3D BIM models, and file revisions. Its browser-based viewer supports over 60 file formats, including native BIM, IFC, CAD, drawings, spreadsheets, and panoramas, without requiring plugins or specialized software licenses.

Key capabilities include:
- Manage different versions of project files and track revision history.
- Review and coordinate BIM models directly in the browser.
- Add comments and collaborate with site teams, subcontractors, and clients.
- Use naming conventions, review workflows, and automated transmittals to manage documents.

### Construction Project Management

CUBE connects document management with field and commercial operations, helping teams manage different stages of project delivery.

Key capabilities include:
- Manage RFIs and conduct site inspections.
- Track contracts and process BOQ-driven billing.
- Perform model-based quantity takeoffs.
- Synchronize schedules with Primavera P6 and Microsoft Project.
- Choose between CUBE Cloud, private cloud, and on-premise deployment.

CUBE is backed by ISO 27001 and SOC 2 Type II security certifications.
